# ERP-PYTHON-POO-JULIAN-SANCHEZ
Sistema ERP en Python usando POO


#Descripción
Sistema ERP desarrollado en Python utilizando Programación Orientada a Objetos.
El sistema permite:
* Inicio de sesión
* Gestión de productos
* Ventas
* Reportes
* Control de stock
* Persistencia en JSON

#Conceptos POO implementados
* Herencia
* Polimorfismo
* Encapsulamiento
* Validaciones

#Roles
#Administrador
* Agregar productos
* Vender
* Ver reportes
#Cajero
* Vender
* Buscar productos
* Ver reportes

# Tecnologías usadas
* Python
* JSON

# Ejecución
python main.py
